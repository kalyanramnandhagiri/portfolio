# Kalyan Ram — React Portfolio

A responsive one-page portfolio for a Java Full Stack Developer.

## Tech Stack
- React.js
- Vite
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Before publishing

Update these placeholders in `src/main.jsx`:
- GitHub URLs (`href="#"`)
- LinkedIn URL (`href="#"`)
- Email (`your-email@example.com`)
- Resume PDF is included in `public/Kalyan-Ram-Resume.pdf`

You can also replace project descriptions and add real GitHub/live-demo links.

## Resume
The supplied resume PDF has been added to the portfolio and is available through the Resume button.

## Personal links
Replace the placeholder GitHub and LinkedIn URLs in `src/main.jsx` with your actual profile URLs.
